| [stm32f4_cmake](stm32f4_cmake)                            | CMake                     | C         | USB CDC Serial    | STM32F411 Discovery   |
| [ti_c28x_launchxl_f280049c](ti_c28x_launchxl_f280049c)    | Code Composer (theia)     | C++       | Serial            | LaunchXL-F280049C     |
